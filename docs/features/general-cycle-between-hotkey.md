## Cycle between with the hotkey

Press the "Noise control" hotkey to cycle between the selected noise control modes.

| Option             | Description                          |
| ------------------ | ------------------------------------ |
| Off                | —                                    |
| Transparency       | —                                    |
| Adaptive           | Requires support from the headphones |
| Wind cancellation  | Requires support from the headphones |
| Noise cancellation | —                                    |
